# 🔍 네트워크 트래픽 모니터링 및 이상 탐지

> SGA솔루션즈 TTS사업본부 지원 포트폴리오 | 컴퓨터정보학부 이형석

## 📋 프로젝트 개요

Wireshark와 Nmap을 활용하여 실시간 네트워크 트래픽을 캡처하고 정상 트래픽과 이상 트래픽을 분류·분석한 프로젝트입니다.

## 🛠️ 사용 도구

| 도구 | 버전 | 용도 |
|------|------|------|
| Wireshark | 4.6.6 | 패킷 캡처 및 트래픽 분석 |
| Nmap | 7.99 | 포트 스캔 시뮬레이션 |
| Npcap | 1.88 | Windows 패킷 캡처 드라이버 |

## 🔬 실습 내용

| 실습 | 필터 | 결과 |
|------|------|------|
| 전체 트래픽 캡처 | 없음 | ARP, UDP, QUIC 등 다양한 프로토콜 확인 |
| DNS 트래픽 분석 | `dns` | 접속 도메인 목록 확인 |
| TCP RST 이상 탐지 | `tcp.flags.reset == 1` | RST 패킷 32개 탐지 |
| 포트 스캔 시뮬레이션 | `tcp.flags.syn == 1 and tcp.flags.ack == 0` | SYN 패킷 99개 탐지 |

## ⚠️ 이상 트래픽 탐지 결과

| 구분 | 패턴 | 판단 |
|------|------|------|
| 정상 | DNS Query/Response | 정상 |
| 정상 | QUIC (구글 서비스) | 정상 |
| 주의 | TCP RST 다수 발생 | 방화벽 차단 의심 |
| 위험 | SYN Scan 패턴 | 포트 스캔 공격 패턴 |
